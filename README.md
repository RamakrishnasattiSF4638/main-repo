# Simple Todo App

A clean, modern, and lightweight Todo application built with HTML, CSS, and vanilla JavaScript.

## Features

- **Create Tasks:** Quickly add new tasks via input form or keyboard (Enter).
- **Toggle Completion:** Check off completed items with immediate visual feedback.
- **Filter Tasks:** Easily switch between "All", "Active", and "Completed" views.
- **Delete Tasks:** Remove individual tasks.
- **Clear Completed:** Bulk remove completed tasks with a single click.
- **Persistent State:** Automatically saves all items to `localStorage`.
- **Responsive & Accessible:** Clean, accessible styling powered by modern CSS.
